How to Use

🛰️ Transponder (GPS Sender)

Simulates a vehicle broadcasting GPS location data.

  • Requires device location permission
  • Sends coordinates via MQTT broker
  • Displays real-time speed and coordinates

Best on: Mobile with GPS or desktop with location spoofing

🗺️ Dashboard (Map Receiver)

Listens for transponder data and displays it on a live map.

  • Shows vehicle location with trail
  • Reverse-geocodes the address
  • Displays related news context
  • Updates in real time

Best on: Desktop or tablet for full map view

Quick Start

Follow these steps to see the tracker in action:

  1. Open Transponder on a device with GPS enabled
  2. Click "Activate Transponder"
  3. Allow location access when prompted
  4. Open Dashboard in another browser/tab
  5. Watch the map update with your location in real time

Architecture

Technology Stack

  • Mapping: Leaflet.js + OpenStreetMap
  • Messaging: MQTT via HiveMQ public broker
  • Geocoding: OpenStreetMap Nominatim (reverse geocoding)
  • News: RSS2JSON bridge to BBC World News
  • Frontend: Plain HTML, CSS, JavaScript (no build tools)

Development

To run the tracker locally:

$ git clone https://github.com/Suok9/tracker.git $ cd tracker $ python -m http.server 8000

Then open:

  • http://localhost:8000/transponder.html
  • http://localhost:8000/dashboard.html
